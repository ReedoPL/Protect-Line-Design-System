App layer · type and density

Small type, still Poppins

The website reads at 16px with generous line spacing. Screens full of calls, scores and filters need a tighter scale. Same typeface, smaller steps, shorter lines — and a monospace for anything that has to line up.

The app scale

Use it for product UI. Keep the marketing scale (16px body, 1.6 line height) for anything a customer reads as a page: emails, the website, letters, long help articles.

Why figures use a monospace

Poppins, as Google Fonts serves it, has proportional figures only: a “1” is about half the width of a “0”. Measured in Chromium, font-variant-numeric: tabular-nums changes nothing. Right-aligning is not enough — the decimal points still wander. JetBrains Mono matches Poppins’ x-height at the same size and keeps every digit the same width.

Poppins

Right-aligned. Decimal points drift.

1,111.1188.254,071.9011.10£908.00

Poppins + tabular-nums

No effect: the feature is not in the font.

1,111.1188.254,071.9011.10£908.00

JetBrains Mono

Every digit the same width. Columns line up.

1,111.1188.254,071.9011.10£908.00

Each pink tick marks a decimal point: they stagger in Poppins and stack in the monospace. A big standalone figure (a stat tile, a hero number) stays in Poppins — tabular spacing makes large numbers look loose.

Keeping dense tables readable

Poppins is a wide, round face. At 13px it stays clear, but it uses more width per word than a condensed sans, so dense screens need a few habits.

Do

  • 13px, 36px rows for data tables; 14px everywhere else.
  • Leave tracking at 0 below 16px. Tighten (−0.01em) only for headings 18px and up.
  • Weight, not size, for hierarchy: 500 for the primary column, 400 and muted ink for the rest.
  • Figures in the monospace, right-aligned, with the same decimal places down a column.
  • Sentence-case headers at 12px, in subtle ink, so the data is the loudest thing.
  • Truncate long text with an ellipsis and keep the full value in a tooltip or the detail view.

Don't

  • Go below 12px, even for footnotes.
  • Set whole columns in bold or in pink. Pink in a table is for one thing: the selected row's bar.
  • Use all-caps headers longer than a word or two; they widen fast in Poppins.
  • Use Lora in product UI. It is for quotes and expressive headings on marketing pages.
  • Squeeze line height under 1.33 — Poppins’ tall x-height needs the room.
  • Reach for Inter or a system font to fit more in. Drop a column instead.
